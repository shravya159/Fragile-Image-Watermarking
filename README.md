# Fragile Image Watermarking for Tamper Detection

## Project Description
This project detects unauthorized modifications in digital images using fragile image watermarking techniques.

## Technologies Used
- Python
- Streamlit
- NumPy
- Pillow
- SHA-256 Hashing

## Features
- Upload original images
- Generate fragile watermarks
- Verify image authenticity
- Detect image tampering
- Display tamper detection maps
- Download watermarked images

## How to Run

1. Install Python.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`
